# Campus Event Registration System

## 1. Project Structure & Modules (Q1)
- **Data Representation (`Student` Class):** Stores student name, registration number, and selected workshop.
- **Registration Logic (`WorkshopManager` Class):** Handles input validation, prevents duplicate registration numbers, and lists participants.
- **Input/Output (`main` Function):** Provides the CLI menu and displays messages.

## 2. Design Principles (Q1)
- **Abstraction & Modularity:** Separating data and logic into classes makes the code easier to test, debug, and maintain without breaking other parts.
- **Principle Used:** Separation of Concerns (SoC) and Single Responsibility Principle (SRP).
